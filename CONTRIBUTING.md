# Contributing to Kimbilio Mali

Thank you for your interest in contributing to Kimbilio Mali! We strive to maintain a clean, professional, and secure codebase. Please follow these guidelines when contributing:

## Code of Conduct
- Be respectful and collaborative.
- Maintain high coding standards and clean architecture.

## Development Workflow
1. Fork the repository and create your feature branch from `main`.
2. Ensure all code adheres to project linter standards (`eslint`, `flake8`).
3. Run security scans (e.g., `gitleaks`) to ensure no sensitive API keys or credentials are committed.
4. Submit a pull request with a clear description of your changes.

## Commit Guidelines
- Write clear, concise commit messages.
- Ensure all author and committer metadata correctly reflects your professional identity.
