# Kimbilio Mali

> Advanced Real Estate Investment and Rental Profitability Tracker

## Overview
Kimbilio Mali is a comprehensive, production-grade real estate portfolio management and rental profitability tracking platform. Designed for modern investors, property managers, and financial analysts, it provides real-time analytics, cash flow forecasting, expense tracking, and market trend visualization.

## Features
- **Properties Dashboard**: Comprehensive overview of real estate holdings, occupancy rates, and valuation metrics.
- **Rental & Lease Management**: Track active leases, rental yields, and tenant payment histories.
- **Expense & Transaction Tracking**: Monitor operational costs, maintenance expenses, and net operating income (NOI).
- **Cash Flow Projections**: Automated monthly cash flow calculations and negative cash flow risk alerts.
- **Market Trends**: Data-driven insights into regional real estate appreciation and rental yield trends.
- **Robust REST API & SQL Queries**: Fully structured backend data models and SQL reporting queries.

## Tech Stack
- **Frontend**: React, TypeScript, TailwindCSS, Lucide Icons, Recharts
- **Backend**: Python (Flask / FastAPI), RESTful APIs
- **Database**: MySQL / TiDB / S3 Storage Integration
- **Containerization**: Docker & Docker Compose

## Quick Start (Docker)
To run the entire platform locally using Docker:
```bash
docker-compose up --build
```
